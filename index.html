    How it works

    Simple helpdesk workflow

    1. 1
      Submit

      A customer raises a request with details and optional files.

    2. 2
      Review

      Agents see the request in the shared inbox.

    3. 3
      Work

      Agents add internal notes, send replies, and update the status.

    4. 4
      Resolve

      Once complete, the request can be marked as resolved or closed.
